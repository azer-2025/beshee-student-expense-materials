## 启动前配置

1. 查看目标子项目的 `pom.xml`、`package.json` 和已有 README，选择对应的 Java、Maven、Node.js 环境。
2. 根据应用配置创建数据库，填写自己的数据库、邮件、Redis、模型 API 等连接信息。上传副本中的配置口令已替换为 `CHANGE_ME`。

4. 前端先安装依赖，再使用各 `package.json` 中定义的命令。后端按对应 Maven 模块的说明启动。
